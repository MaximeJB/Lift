# Installer Storybook

**Objectif** : Avoir un catalogue de composants consultable sur ton téléphone (rendu natif) et dans le navigateur — prérequis pour tester les primitives visuellement.

Initialise Storybook pour React Native, ajoute l'addon `react-native-web`, mets en place la bascule app ↔ Storybook via variable d'environnement, et ajoute le script de régénération de l'index des stories dans `package.json`.

**Ressources** :

- [github.com/storybookjs/react-native](https://github.com/storybookjs/react-native)
- Recherche : `storybook react native expo router setup 2024`
