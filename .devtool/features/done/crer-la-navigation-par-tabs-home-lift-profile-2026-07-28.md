# 10. Créer la navigation par tabs (Home, Lift, Profile)

**Objectif** : Bottom tab navigator avec 3 onglets — structure de navigation principale de l'app. C'est le squelette dans lequel tous les écrans futurs s'insèrent.

Avec expo-router, c'est un dossier `app/(tabs)/` avec un fichier `_layout.tsx`. Chaque tab est un fichier.

**Ressources** :

- [docs.expo.dev](http://docs.expo.dev)[ — Tabs layout](https://docs.expo.dev/router/layouts/tabs/)
- Recherche : `expo router tabs layout typescript bottom navigation`
