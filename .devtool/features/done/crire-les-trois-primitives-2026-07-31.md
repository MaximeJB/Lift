# Écrire les trois primitives

**Objectif** : Poser les trois briques qui portent ton ADN visuel — `Hairline`, `Text`, `Button` — avec une story par état pour chacune.

`Hairline` utilise `StyleSheet.hairlineWidth` (seule exception légitime à la prop `style`). `Text` expose une prop `variant` qui mappe sur des classes. `Button` expose `variant`, `loading`, `disabled`. Les états sortent des sections "cas limites" de ta spec, pas de ton imagination. À écrire toi-même, sans déléguer.

**Ressources** :

- [reactnative.dev](http://reactnative.dev)[ — StyleSheet.hairlineWidth](https://reactnative.dev/docs/stylesheet#hairlinewidth)
- Recherche : `react native StyleSheet hairlineWidth border retina`
